# Resource logos

Locally stored platform logos keep resource cards independent of external image servers.

- `moodle.svg`: https://github.com/moodle/moodle/blob/main/public/pix/moodlelogo.svg
- `library.svg`: original open-book symbol for the school's library service.
- `iltc.png`: ILTC HNSF logo supplied by the school website owner.
- `sndl.jpg`: https://sndl.cerist.dz/images/logo_sndl_deg_mini.jpg
- `progres.png`: https://progres.mesrs.dz/webequivalence/resources/images/logo2.png
- `edx.svg`: https://www.edx.org/trademark-logos/edx-logo-elm.svg
- `dspace.svg`: https://github.com/DSpace/dspace-angular/blob/main/src/assets/images/dspace-logo.svg

Brand marks belong to their respective owners. Institutional services without a separate logo use the existing ENSF crest. Administrators can change each service's logo under **Services numériques**.
